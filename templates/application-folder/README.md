# Application folder template

Each application gets a folder named `APP-0001-company-role` inside exactly one status folder.

- `job-description.md`: copied posting, source URL, and verification date.
- `role-assessment.md`: eligibility, fit, priority, unknowns, and duplicate check.
- `claim-map.md`: every tailored claim and its evidence-bank reference.
- `materials/`: editable and PDF resume, cover letter, and short answers.
- `submission-evidence/`: confirmation or user-provided proof after applying.
- `notes.md`: research, decisions, and next action.

The folder moves as the workbook status changes; its ID never changes.

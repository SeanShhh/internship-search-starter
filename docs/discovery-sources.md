# Recommended internship-discovery sources

Use these sources to find leads. A listing is not proof that a role remains open or that a student qualifies: before moving a role into the tracker, check the employer's own posting and record the date checked.

| Source | Best use | How to use it responsibly |
| --- | --- | --- |
| [InternDock Summer 2027 list](https://www.interndock.com/tracker/guides/summer-2027-internships-list) | A curated Summer 2027 starting list across role types. | Open promising listings, then find the matching employer careers page. |
| [SimplifyJobs Summer 2027 Internships](https://github.com/SimplifyJobs/Summer2027-Internships) | Software engineering, data science, AI, quant, product, and hardware roles. The project describes its list as updated daily. | Use its role links as leads; retain its URL as the discovery source and verify the employer link. |
| [intern-list.com](https://www.intern-list.com/) | Broad U.S. and Canada search by function, including business, creative, public-sector, and technical roles. | Filter to the student's criteria, then verify the employer listing and eligibility. |
| Employer career sites | The definitive application page and most reliable source for deadline, location, and eligibility. | Prefer this URL for applying and mark a role uncertain if it cannot be verified. |
| Campus career portal and career center | Campus-specific employers, programs, and recruiting events. | Add the portal as the source when it is the only available posting, then note any missing details. |

## Discovery workflow

When someone asks to find internships, first use their confirmed goals, timing, locations, work authorization, class year, and role interests. Search the sources above alongside targeted employer career pages. For each credible lead, preserve the discovery URL, employer posting URL when available, description, verification date, eligibility result, duplicate check, and the reason it fits. The assistant recommends a priority; the student decides whether to prepare or apply.

If a listing site and an employer page disagree, keep the discrepancy visible and rely on the employer page. If the official page is gone, record the listing as unavailable instead of presenting it as open.

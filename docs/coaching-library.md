# Coaching library

| Principle | Applies when | Source | Type | Practical use |
| --- | --- | --- | --- | --- |
| Match evidence to the role's actual work | Tailoring a resume or response | Resume review practice | General guidance | Select a small set of complementary examples, then explain the match. |
| Specific, verified detail is more persuasive than generic enthusiasm | Writing applications and outreach | Writing practice | General guidance | Prefer concrete responsibilities and outcomes; ask when a detail is not supported. |
| Warm context changes the outreach approach | Networking | Networking practice | Situational tradeoff | Reference an established connection only when it is real; use concise, researched cold outreach otherwise. |
| One outcome does not prove a strategy | Reflection | Evaluation practice | General guidance | Record feedback and patterns over time without overfitting to a single response. |

This library contains paraphrased principles, not private notes. Add a source, situation, and type whenever adding advice. User preferences belong in `private/writing-guide.md`, not here.

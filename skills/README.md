# Shared workflows

These workflows work in both Claude Cowork and Codex through the shared `AGENTS.md` and `CLAUDE.md` entrypoints. They contain no personal information and may be published with the starter.

| Workflow | Use it when |
| --- | --- |
| `profile-memory` | Starting, resuming, or closing any coaching session. |
| `resume-materials` | Creating or revising a resume, cover letter, or short-answer response. |
| `role-discovery` | Finding, verifying, prioritizing, or deduplicating internship postings. |

Ask in ordinary language, such as “find internships that fit me this week” or “tailor my resume to APP-0004.” The assistant chooses the matching workflow.

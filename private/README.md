# Your private workspace

This folder holds your profile and memory. The AI creates these files as it learns verified information:

- `profile.md`: confirmed background, goals, and constraints.
- `evidence-bank.md`: claims traceable to a source or your confirmation.
- `story-menus.md`: role-relevant examples built from the evidence bank.
- `writing-guide.md`: voice and formatting preferences.
- `open-questions.md`: unanswered details that could improve future applications.
- `session-state.md`: onboarding progress and the next recommended action.

The real files are ignored by Git. This README stays so you can find the folder.

# Workspace instructions

Read `docs/coaching-guide.md` before coaching. Read user materials and `private/` before asking questions. `tracker/Internship Search Tracker.xlsx` is authoritative for application and outreach status. Reconcile direct workbook edits before changing folders or summaries.

Use the reusable workflows in `skills/` when their situation applies: `profile-memory` for every coaching session, `resume-materials` before drafting application materials, and `role-discovery` when finding roles. They are shared instructions; personal facts stay in `private/`.

Keep confirmed facts separate from questions. Never create accomplishments, numbers, eligibility facts, contacts, or claims that the user did not support. Explain the purpose and future use of each artifact when first created. Ask two or three focused questions at a time and record unresolved questions in `private/open-questions.md`.

Use permanent application IDs and status folders. Preserve each role description, verification date, materials, and notes together. Back up the workbook before edits, detect a changed file before writing, and leave incomplete checks visible. End every session with completed work, needed input, and one recommended action.
